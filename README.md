# Generative AI Study Repository

이 레포지토리는 **생성형 AI(Generative AI)** 및 **딥러닝 학습**을 위한 Jupyter Notebook 모음집입니다.
컴퓨터 비전, 자연어 처리, 벡터화, RNN/LSTM/Transformer, Object Detection, GAN 등 다양한 주제를 실습과 함께 학습할 수 있도록 구성되어 있습니다.

---

## 📂 폴더/노트북 구성

### 1. 기초 이론 및 벡터화

* `1. 컴퓨터 비전.ipynb` : 컴퓨터 비전 개요
* `10. 자연어 처리.ipynb`, `10. 자연어 처리 복습.ipynb` : 자연어 처리 기초
* `11. 벡터화.ipynb`, `11. 벡터화 복습.ipynb` : 텍스트 임베딩과 벡터 표현
* `12. 신경망 기반의 벡터화.ipynb` : Word2Vec, GloVe 등 딥러닝 임베딩 방법

### 2. 순환 신경망 및 시계열 모델

* `13. RNN.ipynb`, `13. RNN_코스피예측.ipynb` : 순환 신경망과 시계열 예측
* `14. LSTM과 GRU.ipynb`, `14(2). LSTM+CNN 복습.ipynb` : LSTM, GRU, CNN 결합 모델
* `15. Seq2Seq.ipynb` : 시퀀스-투-시퀀스 번역/요약 모델
* `16. 어텐션 메커니즘.ipynb` : Attention 구조 이해
* `17. 트랜스포머.ipynb` : Transformer 심화 학습
* `18. 사전 학습된 언어 모델(PLM).ipynb`, `19. Language Model 발전.ipynb` : BERT, GPT 등 대규모 PLM 학습

### 3. 컴퓨터 비전 및 Object Detection

* `2. Object Detection.ipynb` : 객체 탐지 기초
* `2(2). Object Detection 시각화 추가.ipynb` : 시각화 기능 확장
* `20. ViT(Vision Transformer).ipynb` : 비전 트랜스포머 기반 이미지 분류
* `21. Sokoto Coventry Fingerprint Dataset.ipynb` : 지문 인식 데이터셋
* `22. 수학 인식 데이터.ipynb` : 수학 공식 인식
* `4. 이한류 CCTV 데이터셋.ipynb` : CCTV 영상 데이터 활용
* `5. Segmentation.ipynb` : 이미지 분할
* `6. 차량 파손 데이터셋.ipynb` : 차량 파손 탐지

### 4. 비지도 학습 및 생성 모델

* `7. 비지도 학습.ipynb`, `7. 비지도 학습 복습.ipynb` : 클러스터링, 차원 축소 등 비지도 학습
* `8. 오토인코더.ipynb`, `8. 오토인코더 복습.ipynb` : 차원 축소 및 데이터 재구성
* `9. GAN.ipynb`, `9. GAN 복습.ipynb` : 생성적 적대 신경망(Generative Adversarial Network)

## 🚀 학습 목표

* 생성형 AI의 핵심 이론과 응용 학습
* 텍스트/이미지/시계열 데이터를 활용한 다양한 모델 구현
